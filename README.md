# Alumnos y Cuotas · actualizaciones

Este repositorio publica las versiones nuevas de la app **Alumnos y Cuotas** (FACK Music).
Las apps instaladas leen `version.json` y, si hay una versión más nueva, descargan `index.html`.

- No contiene datos de alumnos, cuotas ni la dirección del servidor.
- `base` indica la versión instalada mínima necesaria: si una actualización requiere reinstalar la app, se sube ese número.
- Quien tiene acceso de escritura a este repositorio puede cambiar lo que hacen las apps: mantené la cuenta con verificación en dos pasos.
